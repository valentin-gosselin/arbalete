# Privacy policy / Politique de confidentialité

## English

Arbalète does not collect, send or sell any data. It contains no analytics, no tracking and makes no network request of its own.

- Your spaces, colors, icons and favorites are stored by Firefox in the extension storage. If you use Firefox Sync with add-ons enabled, Firefox syncs them between your own devices through your Firefox account. Arbalète never sees your account.
- Which tab belongs to which space is stored by Firefox in its session data, on your computer only.
- Favicons shown in the sidebar are the ones Firefox already loaded for your tabs.
- The "Hide Firefox's own tabs" installer is generated locally and only edits files in your own Firefox profile.
- Export files are created on your computer and go wherever you save them.

Split view is optional. The first time you use it, Firefox asks for access to all websites: Arbalète then removes the "do not display in a frame" headers (X-Frame-Options, CSP frame-ancestors) of pages loaded inside its own split view page, and notes their address to show it in the split view. Before showing YouTube in split view, it also clears YouTube's service worker (browsing data permission), because that worker would otherwise keep the page from being framed; YouTube reinstalls it on your next visit. Nothing else is read, stored or sent. You can revoke this permission at any time in about:addons.

The same "access to all websites" permission, if granted, also lets Arbalète show its dialogs (settings, space editor…) over the current page instead of under its toolbar button. It is optional and only used to display those dialogs.

Searching your history in quick search is optional (history permission, asked when you turn it on in the settings). The history is read on your computer only, while you type in quick search.

Quick search suggestions are off by default. If you enter a suggestion address in the settings (your own search engine), what you type in quick search is sent to that address only, to get suggestions, as Firefox's own search bar does.

Permissions are used only for what the extension does: reading and hiding tabs (spaces), sessions (remembering each tab's space), storage (settings), containers and cookies (one container per space), menus (right-click menus), tab groups, clipboard (copy the tab address), search (web search from quick search) and theme (optional tint of Firefox in the space colors).

Builds downloaded from GitHub (outside addons.mozilla.org) let Firefox check for new versions in the updates.json file of the GitHub repository, as Firefox does with addons.mozilla.org for listed add-ons. This request is made by Firefox and carries no personal data.

## Français

Arbalète ne collecte, n'envoie ni ne vend aucune donnée. Aucune mesure d'audience, aucun pistage, aucune requête réseau de sa part.

- Vos espaces, couleurs, icônes et favoris sont enregistrés par Firefox dans le stockage de l'extension. Si vous utilisez Firefox Sync avec les modules complémentaires, Firefox les synchronise entre vos propres appareils via votre compte Firefox. Arbalète n'a jamais accès à ce compte.
- L'espace de chaque onglet est mémorisé par Firefox dans ses données de session, uniquement sur votre ordinateur.
- Les favicons affichés sont ceux que Firefox a déjà chargés pour vos onglets.
- L'installateur « Masquer les onglets natifs de Firefox » est généré sur votre ordinateur et ne modifie que les fichiers de votre propre profil Firefox.
- Les fichiers d'export sont créés sur votre ordinateur et vont là où vous les enregistrez.

La vue scindée est facultative. À la première utilisation, Firefox demande l'accès à tous les sites : Arbalète retire alors les en-têtes « ne pas afficher dans un cadre » (X-Frame-Options, CSP frame-ancestors) des pages chargées dans sa propre page de vue scindée, et note leur adresse pour l'afficher. Avant d'afficher YouTube dans la vue scindée, elle efface aussi le service worker de YouTube (permission « données de navigation »), qui empêcherait sinon l'affichage en cadre ; YouTube le réinstalle à la visite suivante. Rien d'autre n'est lu, conservé ni envoyé. Cette permission se retire à tout moment dans about:addons.

La même autorisation « accès à tous les sites », si vous l'accordez, permet aussi à Arbalète d'afficher ses fenêtres (réglages, modification d'un espace…) par-dessus la page plutôt que sous son bouton. Elle est facultative et ne sert qu'à afficher ces fenêtres.

La recherche dans l'historique est facultative (permission « historique », demandée quand vous l'activez dans les réglages). L'historique est lu sur votre ordinateur uniquement, pendant que vous tapez dans la recherche rapide.

Les suggestions de la recherche rapide sont désactivées par défaut. Si vous indiquez une adresse de suggestions dans les réglages (votre propre moteur), ce que vous tapez dans la recherche rapide est envoyé à cette adresse seulement, pour obtenir des suggestions, comme le fait la barre de recherche de Firefox.

Les permissions servent uniquement au fonctionnement : lire et masquer les onglets (espaces), sessions (mémoriser l'espace de chaque onglet), stockage (réglages), conteneurs et cookies (un conteneur par espace), menus (clic droit), groupes d'onglets, presse-papiers (copier l'adresse de l'onglet), recherche (recherche sur le Web depuis la recherche rapide) et thème (teinte facultative de Firefox aux couleurs de l'espace).

Les versions téléchargées depuis GitHub (en dehors d'addons.mozilla.org) permettent à Firefox de vérifier les nouvelles versions dans le fichier updates.json du dépôt GitHub, comme il le fait avec addons.mozilla.org pour les modules listés. Cette requête est faite par Firefox et ne contient aucune donnée personnelle.
